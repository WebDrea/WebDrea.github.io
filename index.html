StomelyCompanion — Final Year Project

React • Vite • JavaScript • localStorage • Vercel

A digital companion application for ostomy patients, bridging the gap between hospital discharge and home recovery. Built as a modular React SPA with four integrated tools: a rule-based symptom checker with severity scoring, a structured learning hub linking trusted external resources, a supply tracker with low-stock alerts, and a full CRUD contact manager for storing stoma nurses, GPs, and suppliers.

Designed offline-first using localStorage — no external data transmission, keeping all patient data on-device and simplifying GDPR compliance. Rule-based logic (not AI/ML) was chosen to ensure transparent, auditable outputs appropriate for a healthcare context.
